工程師 / 最高權限後台規格
日期：2026-08-28

一、目前原則

1. 多客戶 / tenant 底層保留。
2. 客戶版 UI 預設隱藏多客戶管理。
3. 多客戶管理只出現在工程師 / 最高權限後台。
4. 不做登入頁連點後門。
5. 工程師後台使用正式後端權限保護。
6. 工程師後台入口網址尚未命名，實作入口前必須先詢問業主。

二、現有權限基礎

目前後端已有最高權限判斷：

1. owner email
2. system_owner permission
3. API 層級的最高權限檢查

受保護的能力包含：

1. 取得 owner scope 資料
2. 建立 / 修改 tenant
3. 查看系統使用量
4. 切換多客戶檢視範圍

三、待入口命名後要做的事

1. 決定工程師後台入口網址。
2. 只有從該入口進入時，才顯示多客戶管理 UI。
3. 一般 /admin 登入即使是客戶管理員，也只看到自己 tenant 的功能。
4. 後端 API 保持最高權限檢查，不只靠前端隱藏。
5. 若非最高權限使用者直接打入口網址，需顯示無權限或導回一般後台。

四、建議驗收標準

1. 一般客戶帳號登入 /admin 看不到多客戶管理。
2. 一般客戶帳號直接打工程師入口也不能使用。
3. 最高權限帳號登入一般 /admin 時，不影響客戶版日常操作。
4. 最高權限帳號進入工程師入口後，可看到 tenant 管理與系統使用量。
5. Network/API 直接呼叫仍會被權限擋下。

五、未完成原因

工程師後台入口網址需要由業主命名後才可實作。
