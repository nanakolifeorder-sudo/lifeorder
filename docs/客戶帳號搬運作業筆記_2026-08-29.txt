   - 建立客戶 tenant、P01 專案、後台管理員帳號。
   - 指令：npm run client:db:setup

三、Supabase 操作流程

1. 進 Supabase Dashboard。
2. New project。
3. Project name 建議：nanako-lifeorder-booking 或 lifeorder-crm。
4. Region 建議選 Asia Pacific / Tokyo 或 Singapore，以接近台灣為主。
5. 設定 database password，這個密碼由你或客戶保管。
6. 建好後到 Database > Connect。
7. 選 Transaction pooler。
8. 複製 URI，格式類似：
   postgresql://postgres.xxxxx:[YOUR-PASSWORD]@aws-xxx.pooler.supabase.com:6543/postgres
9. 將 [YOUR-PASSWORD] 換成 Supabase database password。
10. 在本機建立 .env.client，填入 DATABASE_URL 與 CLIENT_ADMIN_PASSWORD。
11. 執行：npm run client:db:setup

五、Google Cloud 操作流程

1. 進 https://console.cloud.google.com/。
2. 確認右上角帳號是 nanako.lifeorder@gmail.com。
3. 建立新 project，建議名稱：Life Order Booking CRM。
4. 啟用 API：
   - Gmail API
   - Google Calendar API
5. OAuth consent screen：
   - App name：Life Order Booking CRM
   - User support email：nanako.lifeorder@gmail.com
   - Developer contact email：nanako.lifeorder@gmail.com
   - Publishing status 初期可先 Testing；若只給內部帳號使用，可先加入 test users。
6. Scopes：
   - Gmail send
   - Calendar read busy / events
7. Credentials > Create OAuth client ID。
8. Application type：Web application。
9. Authorized redirect URI：
   - Vercel 完成後填 https://正式網域/api/oauth-callback
   - 若先用目前測試站，可填 https://dm-booking-saas.vercel.app/api/oauth-callback，但客戶獨立站上線後要改回客戶正式網址。
10. 取得 GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET。

六、GitHub 搬運流程
